# ChefMom - دستیار هوشمند آشپزخانه مامان‌جون

![ChefMom Banner](https://github.com/user-attachments/assets/0aa67016-6eaf-458a-adb2-6e31a0763ed6)

این پوشه یک اپ جداگانه است که نسخهٔ آشپزیِ Farsi Content Pro را برای مامان‌جون پیاده‌سازی می‌کند؛
یک کمک‌آشپز هوشمند که همیشه کنار مامان‌جون است تا بگوید «امروز چی بپزم؟».

## ✨ ChefMom چه کار می‌کند؟

### 🎯 حالت‌های اصلی (Modes)

- **ایده رسپی سریع**: از روی مواد موجود در خانه یا شرایط (مثلاً «شام سریع برای دو نفر»)
  چند ایده غذای ساده و سریع پیشنهاد می‌دهد.
- **برنامه هفتگی غذا**: برای چند روز یا یک هفته، منوی غذاهای خونگی و متنوع برای خانواده می‌چیند.
- **رسپی کامل مرحله‌به‌مرحله**: برای یک غذا، مواد لازم با مقدار دقیق، مراحل شماره‌دار و نکته‌های مهم را می‌نویسد.
- **سالم‌ترش کن**: یک غذای دلخواه را می‌گیرد و نسخهٔ سالم‌تر، کم‌چرب‌تر یا مناسب رژیم را پیشنهاد می‌دهد.
- **نکته‌ها و ترفندهای آشپزخانه**: فوت‌وفن‌هایی برای خوش‌طعم‌تر شدن غذا، نگهداری مواد، فریز کردن، و تمیزکاری می‌دهد.

### 💬 چت‌بات ChefMom

- یک چت‌بات با شخصیت «ChefMom» که مستقیماً با «مامان‌جون» حرف می‌زند.
- لحن کاملاً خودمانی، محترم و صمیمی؛ همیشه مخاطب را «مامان‌جون» صدا می‌زند.
- در جواب‌ها تا حد امکان نکته‌های عملی آشپزی و تجربهٔ آشپزخانه اضافه می‌کند.

### 🚀 امکانات اپلیکیشن

- ✅ پنل «اصلاح / تغییر متن» برای ویرایش رسپی یا توضیحات با یک دستور ساده
- ✅ پشتیبانی از Gemini 2.5 (Pro و Flash) با چرخش بین چند کلید API
- ✅ تگ‌ها و فیلترهای مخصوص آشپزی (زمان آماده‌سازی، سبک غذا، بودجه، سلامت و ...)

## 🛠️ نصب و راه‌اندازی

> این دستورالعمل‌ها مخصوص پوشهٔ `chefmom/` است.

**پیش‌نیاز:**

- Node.js 18+ (ترجیحاً 20+ برای سازگاری کامل با کتابخانهٔ Gemini)

### ۱. نصب وابستگی‌ها

از ریشهٔ ریپو:

```bash
cd chefmom
npm install
```

### ۲. تنظیم کلیدهای Gemini

در همین پوشهٔ `chefmom/` یک فایل محیطی (که در گیت نادیده گرفته می‌شود) بساز:

```bash
cp .env.example .env
```

و بعد مقادیر را در `.env` تنظیم کن:

```env
# یک کلید تکی
GEMINI_API_KEY=your_gemini_api_key_here

# یا چند کلید برای چرخش بین آن‌ها
# GEMINI_API_KEYS=key1,key2,key3
```

کد، به ترتیب این متغیرها را بررسی می‌کند:

1. `GEMINI_API_KEYS` (لیست کاما جدا)
2. `GEMINI_API_KEY`
3. `API_KEY`

و اگر هیچ‌کدام تنظیم نشده باشند، در زمان اجرا خطا می‌دهد.

### ۳. اجرای برنامه در حالت توسعه

در پوشهٔ `chefmom/`:

```bash
npm run dev
```

به‌طور پیش‌فرض روی `http://localhost:3000` بالا می‌آید.

### ۴. بیلد تولیدی (Production Build)

```bash
npm run build
```

خروجی نهایی در پوشهٔ `dist/` ساخته می‌شود.

برای پیش‌نمایش بیلد تولیدی:

```bash
npm run preview
```

## 🌐 استقرار (Deployment)

در فایل `vite.config.ts` برای ChefMom مقدار `base` روی `/ChefMom/` تنظیم شده است:

```ts
base: '/ChefMom/'
```

این یعنی اگر خروجی `dist/` را روی GitHub Pages در ریپویی با نام `ChefMom`
یا در مسیری مانند `https://USERNAME.github.io/ChefMom/` منتشر کنی،
مسیرها و لینک‌های اپلیکیشن به‌درستی کار خواهند کرد.

در حالت ساده می‌توانی محتوای پوشهٔ `dist/` را در ریشهٔ ریپوی پیج‌های استاتیکت کپی کنی.

## 📖 چند سناریوی استفاده برای مامان‌جون

- «چند ایده شام سریع با سینه مرغ و سیب‌زمینی»: حالت **ایده رسپی سریع**
- «برنامه هفتگی غذای خونگی برای ۴ نفر، کم‌هزینه»: حالت **برنامه هفتگی غذا**
- «رسپی کامل قیمه نذری برای ۱۰ نفر»: حالت **رسپی کامل مرحله‌به‌مرحله**
- «نسخه سالم‌تر قرمه‌سبزی برای کسی که چربی و فشار خون دارد»: حالت **سالم‌ترش کن**
- «نکته برای فریز کردن سبزی قرمه و این‌که سیاه نشود»: حالت **نکته‌ها و ترفندهای آشپزخانه**

در همهٔ این حالت‌ها، لحن و خروجی کاملاً فارسی و مخصوص مامان‌جون طراحی شده است.
